# Weather Subsystem — Procedural Atmosphere & Precipitation

Dynamic GPU-driven weather simulation system for Sphere Studio:
- **Precipitation**: Rain particle compute system with streaks, ground splashes, and ripple normal maps.
- **Snow & Blizzard**: Flutter flutter turbulence simulation with wind shear and procedural snow accumulation.
- **Fog Volume**: Froxel 3D volume grid with exponential height extinction and forward Mie scattering.
- **Volumetric Clouds**: Worley/Perlin noise raymarching with dual-phase powder effect and Beer-Lambert transmittance.
- **Wind & Storms**: 3D vector wind field with curl noise, gust dynamics, and procedural lightning bolt branching.
- **Puddles & Wetness**: Porosity-driven ground wetness accumulation, puddle masking, and dynamic specular reflection.
- **Presets**: Instant transitions between Clear, Rain, Downpour, Snow, Blizzard, Fog, and Thunderstorm.
