# Running Gear (`gen/trailers/running_gear/`)

Shared undercarriage and suspension subsystem used by all trailer generators:
- **Axle Configurations**: Tandem (2x), Tridem (3x), Lift Axle (retractable), and Steerable rear axles.
- **Suspensions**: Pneumatic air-bag bellows, parabolic leaf springs, and hydraulic modular walking beams.
- **Brakes & ABS**: Ventilated disc brakes with red calipers or heavy S-cam drums, plus procedural ABS exciter rings.
