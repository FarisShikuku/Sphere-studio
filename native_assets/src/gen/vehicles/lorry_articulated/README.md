# Articulated Tractor Units (`lorry_articulated/`)

Generates 4 heavy prime movers exposing `fifth_wheel_offset_m` for direct coupling to `TrailerRegistry` semi-trailers:
1. `TRACTOR_CAB_OVER` (Heavy 6x4 COE)
2. `TRACTOR_CONVENTIONAL` (Long-Nose Heavy 6x4)
3. `TRACTOR_EURO_CAB` (4x2 Euro Aero High-Roof Sleeper with side chassis fairings)
4. `TRACTOR_AMERICAN_CAB` (Condo Sleeper 6x4 with dual chrome air cleaners & vertical exhaust stacks)
