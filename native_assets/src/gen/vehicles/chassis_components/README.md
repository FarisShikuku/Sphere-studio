# Shared Chassis Components (`chassis_components/`)

Provides shared heavy-duty drivetrain, frame, tank, and coupling hardware:
- `FUEL_TANK`: Closed cylindrical aluminum fuel tank with twin black retention straps.
- `EXHAUST_STACK`: Dual vertical chrome riser pipes with perforated heat shields.
- `BATTERY_BOX`: Sealed steel battery enclosure + blue AdBlue/DEF cap.
- `ENGINE_BLOCK`: Lowered inline-6 sump respecting ground clearance.
- `DRIVETRAIN`: Propeller shaft & rear axle differential housings.
