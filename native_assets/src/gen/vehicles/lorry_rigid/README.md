# Rigid Lorries (`lorry_rigid/`)

Generates 5 cab-over-engine heavy rigid chassis lorries built to real-world metric dimensions:
1. `LORRY_RIGID_BOX` (18T 4x2 insulated box truck + roof aero visor)
2. `LORRY_RIGID_FLATBED` (Dropside flatbed with animated hinged sideboards)
3. `LORRY_RIGID_TIPPER` (6x4 quarry dumper with pivoting ribbed skip & telescopic hydraulic ram)
4. `LORRY_RIGID_CEMENT_MIXER` (8x4 transit mixer with dual steer axles & helical rotating drum)
5. `LORRY_RIGID_TANKER` (6x4 rigid 20KL tanker with watertight flat-dished end caps)
