# Shared Cab Components (`cab_components/`)

Provides shared modular geometry and PBR texture compute pipelines across all Lorries and Buses:
- `DOOR_LEFT`, `DOOR_RIGHT`: Flanged steel cab doors with belt molding, handle, and opaque reflective glass.
- `WINDSHIELD`: Laminated curved/sloped panoramic windshield with EPDM rubber seal and twin wipers.
- `GRILLE_HEAVY`: Chrome or matte-black slatted radiator grille with dark backing cavity.
- `MIRROR_TRUCK`: Twin-arm heated wing mirrors and wide-angle lower spotters.
