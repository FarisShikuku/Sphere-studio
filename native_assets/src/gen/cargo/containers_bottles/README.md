# Containers & Bottles Procedural Commodity Module

Generates glass bottles, PET beverage bottles, wide-mouth preserve jars, and sanitary tin cans using parametric lathe profile sweeps and PBR optical refraction shaders.

## Supported Variants
- `GLASS_BOTTLE_BEER`: Amber borosilicate glass 330ml bottle with crimped crown cap.
- `PLASTIC_BOTTLE_SODA`: 2.0L polyethylene terephthalate (PET) carbonated soft drink bottle.
- `PLASTIC_BOTTLE_WATER`: 500ml crystal-clear mineral spring water bottle with screw cap.
- `JAR_GLASS`: 500ml wide-mouth glass food preserve jar with tin lug cap.
- `TIN_CAN`: 400g 3-piece sanitary electrolytic tinplate steel food can with paper wrap.
