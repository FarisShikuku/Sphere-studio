# Building Materials Cargo Module (`gen/cargo/building_materials/`)

Procedural geometry and PBR material synthesis for heavy civil, structural, bulk aggregate, glazing, masonry, drywall, and roofing construction commodities.

## Supported Variants (CargoID 41..50)
- `STEEL_IBEAM_6M`: Wide-flange steel HEA 240 beam profile.
- `TIMBER_GLULAM_BEAM`: Cambered multi-lamella structural glulam roof beam.
- `SILICA_SAND_HEAP`: Critical angle-of-repose washed masonry silica sand heap.
- `SILICA_SAND_FIBC_1T`: Superquadric 1-tonne FIBC crane-lifted bulk sand bag.
- `FLOAT_GLASS_STILLAGE`: A-frame stillage rack carrying translucent tempered float glass sheets.
- `HOLLOW_CONCRETE_CMU`: Twin-core hollow concrete masonry blocks on pallet.
- `PRECAST_CONCRETE_SLAB`: Hollow-core prestressed concrete floor slab.
- `GYPSUM_DRYWALL_STACK`: Moisture-resistant layered gypsum plasterboard sheets.
- `CORRUGATED_ROOF_SHEETS`: Sinusoidal corrugated galvanized roofing sheet pack.
- `TERRA_ROOF_TILES_PALLET`: Interlocking terracotta Roman barrel clay tiles.
