# Perishable Goods Procedural Commodity Module

Generates cold-chain cargo, fresh produce harvest crates, ventilated potato sacks, iced seafood, and vacuum-packed wholesale meat.

## Supported Variants
- `PRODUCE_CRATE_TOMATO`: Vented field crate filled with vine-ripened glossy harvest tomatoes.
- `PRODUCE_BAG_POTATO`: 25kg red polymer mesh netting containing washed russet potato tubers.
- `FISH_CRATE`: Fresh salmon fillets packed in crushed flake ice for seafood distribution.
- `MEAT_BOX`: Heavy corrugated wax-coated refrigerated carton with chilled beef primals.
